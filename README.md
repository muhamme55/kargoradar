## 💡 Proje Vizyonu ve Amacı

KargoRadar, lojistik süreçlerini dijitalleştirerek şeffaflık sağlamayı hedefler.

* **⭐ Anlık Takip:** Kullanıcıların gönderi numarası ile kargolarının nerede olduğunu anlık görebilmesi.
* **⭐ Kurumsal Yönetim:** Şirketlerin isteğine gore admin panelinden çalışanlarına yetki verip kargo oluşturabilmesi.
* **⭐ Kullanıcı Dostu Arayüz:** Bootstrap teknolojisi ile her cihazda düzgün çalışan modern tasarım.
